# Plånboksguiden (arbetsnamn)

Affiliatesajt om privatekonomi, byggd med Astro. Statisk sajt, hostas gratis på Netlify eller Cloudflare Pages.

- `npm install` och sedan `npm run dev` för lokal förhandsvisning
- `npm run build` bygger till `dist/`
- Guider ligger i `src/pages/guider/*.md`
- Byt `site` i `astro.config.mjs` när domänen är köpt
